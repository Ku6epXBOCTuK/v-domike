## Функциональные

- [x] **`+error.svelte` не хватало.** При ошибке SvelteKit отдаст дефолтную
      страницу, которая ничего не имеет общего с оформлением. Единственная
      недоделка, которая может ударить по визуалу на ровном месте. Закрыто:
      `src/routes/+error.svelte` + `features/ErrorPanel.svelte`, страница
      рендерится внутри шелла. На статическом хостинге 404 всё равно отдаёт
      хостинг — см. «Известные проблемы» в [`development.md`](development.md).
- [ ] **Корзина не переживает перезагрузку.** Состояние в памяти, тема — в
      `localStorage`. Переход «добавить в корзину → Заказ» работает (клиентская
      навигация), но F5 на `/order` обнулит корзину и покажет пустое состояние.
      Тема и корзина ведут себя по-разному — выровнять.
- [ ] **Три мёртвые кнопки в профиле.** `ProfileRow` рендерит `<button>` без
      обработчика и без ссылки: «История заказов», «Адрес для курьера»,
      «Настроить уведомления». В исходном дизайне они тоже были без `onClick`,
      то есть это точная порта. Нужны страницы или снятие до появления механики.
- [ ] **Мёртвая кнопка уведомлений** в шапке — `IconButton` без `onclick`. Тот
      же случай: в исходнике обработчика не было.
- [ ] **ETA захардкожен.** `EtaPanel` печатает «через 3 минуты», карта статична.
      Фазы готовки и доставки из `concept.md` не реализованы: нет таймера,
      прогресса, текстовых статусов курьера, интерактива на карте. Это
      продуктовый объём, а не дефект.
- [ ] **Нет OG-картинки.** При отправке ссылки в чат превью будет пустым.

## Гигиена

- [ ] **Цена в валюте `coins`.** `DishCard` печатает «420 coins» — английское
      слово в русском интерфейсе. Взято из исходного дизайна, но для
      пользовательского текста это ошибка.
- [ ] **Предупреждение `adapter-static`**:
      `Reading config.kit inside adapters is deprecated`. Приходит изнутри
      адаптера, сборку не ломает. Конфиг уже передан в `sveltekit()` в
      `vite.config.ts`, то есть форма та, которой ждёт апстрим; ждём, пока
      приберут.
- [ ] **Ссылка на удалённый документ.** В `IconButton.svelte` остался
      комментарий `см. docs/port-plan.md` — файла больше нет.
- [ ] **Комментарий в `tokens.css` врёт.** В шапке файла написано, что токен не
      может существовать в одной теме и отсутствовать в другой, и что это
      проверяет гейт. На самом деле `--tone-*` и картографические токены
      намеренно живут только в `:root`, и гейт проверяет обратное. Формулировку
      надо переписать, чтобы она не противоречила строке 86 того же файла.
- [ ] `src/lib/index.ts` — остался комментарий скаффолда, экспортов нет. Файл
      работает как цель импорта для `#lib`, но пустой.
