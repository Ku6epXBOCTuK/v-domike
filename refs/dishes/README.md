# Фотографии блюд

Сюда владелец кладёт снимки, из которых `pnpm images` делает то, что едет в
приложение. Папка вне `static/`, поэтому исходники не достаются к пользователю.

Имя файла — `id` блюда из `src/lib/data/dishes.json`, расширение любое из тех,
что открывает браузер:

```
refs/dishes/borsh.jpg
refs/dishes/tiramisu.png
refs/dishes/okroshka.webp
```

`pnpm images` возьмёт всё из папки, обрежет по центру в 600×682, закодирует
webp, положит в `static/dishes/<id>.webp` и проставит `image` в
`dishes.json`. Если снимок у блюда уже был — файл перезапишется, это
штатный способ поменять неудачный кадр. Список блюд, которым снимок ещё не
достался, печатает `pnpm check:dishes`: их `id` и копируются сюда.

Ошибка в имени файла останавливает скрипт целиком, до обработки: снимок,
которому не соответствует `id`, в приложении просто не покажется.

Формат, геометрия и плейсхолдер описаны в
[`docs/development.md`](../docs/development.md).
