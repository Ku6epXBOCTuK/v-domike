# Исходники иконки и фотографий блюд

Материалы, из которых собираются иконки приложения и снимки блюд. В сборку не
попадают: папка вне `static/`, поэтому 333 КБ исходника и недожатые фотографии
не едут к пользователю.

- `icon.jpeg` — 1024×1024, база. Из неё `pnpm icons` делает иконки в
  `static/`. Цвета владелец правит здесь, потом регенерирует.
- `icon_bad.svg` — автоматическая трасировка этого jpeg (VTracer), с кривыми
  координатами. Как иконка не годится: лежит шаблоном, по которому владелец
  подровняет контуры. Когда появится выровненный вектор, он заменит jpeg, и
  `scripts/make-icons.mjs` перепишется на рендер SVG.
- `dishes/` — фотографии блюд, которые ещё не попали в `static/dishes/`. Имя
  файла = `id` блюда, `pnpm images` режет, кодирует и проставляет `image` в
  `dishes.json`. Подробности — в [`dishes/README.md`](dishes/README.md).

Подробности — в [`docs/backlog.md`](../docs/backlog.md), пункт «Иконку
приложения надо переделать».
