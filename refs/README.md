# Исходники иконки

Материалы, из которых собираются иконки приложения. В сборку не попадают:
папка вне `static/`, поэтому 333 КБ исходника не едут к пользователю.

- `icon.jpeg` — 1024×1024, база. Из неё `pnpm icons` делает иконки в
  `static/`. Цвета владелец правит здесь, потом перегенерирует.
- `icon_bad.svg` — автоматическая трасировка этого jpeg (VTracer), с кривыми
  координатами. Как иконка не годится: лежит шаблоном, по которому владелец
  подровняет контуры. Когда появится выровненный вектор, он заменит jpeg, и
  `scripts/make-icons.mjs` перепишется на рендер SVG.

Подробности — в [`docs/backlog.md`](../docs/backlog.md), пункт «Иконку
приложения надо переделать».
